# Capturas de pantalla

Coloca aquí las imágenes (`.png` o `.jpg`) de los ejercicios en ejecución.
El `README.md` principal ya las referencia, así que solo reemplaza los nombres:

- `portada.png` → página de inicio (`index.jsp`)
- `guia2006.png` → índice de la Guía 2006
- `guia2024.png` → índice de la Guía 2024

Luego haz commit y push:

```bash
git add docs/capturas
git commit -m "docs: agregar capturas de pantalla"
git push origin main
```
